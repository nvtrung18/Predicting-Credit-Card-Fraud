# Task 2.5 — Final DL submission

## Final refit

- Kaggle notebook: [Credit Card Fraud 2.5 Final DL Submission, Version 1](https://www.kaggle.com/code/nvtqx1/credit-card-fraud-2-5-final-dl-submission/versions/1)
- Selected model: MLP baseline from Task 2.4.
- Validation metrics used for selection: ROC-AUC 0.944622 and Average Precision 0.484340.
- Refit: 9 epochs on all 699,960 training rows; 53.24 seconds on a Tesla T4.
- Test rows: 299,984.

## Submission artifact

The generated CSV has columns id,is_fraud, preserves the sample submission ID order, and contains one fraud probability per test row. The local file was checked for 299,984 data rows and probabilities in [0, 1].
